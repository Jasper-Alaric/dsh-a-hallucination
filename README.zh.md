# A-Hallucination · 反幻觉助手

给 DeepSeek Harness 加一层**运行时证据纪律**。它不能让模型变诚实，但能让不诚实的输出**看得见、有代价**。

绝大多数「反幻觉提示词」都栽在同一处：自检写在模型脑子里，所以它想跑才跑。这个插件把检查搬到运行时——**不管模型同不同意，检查都会跑**，而且它会老实说明哪些查得了、哪些查不了。

## 它做什么

| 层 | 行为 |
|---|---|
| 契约 | 在系统提示里注入一段有字数预算的反幻觉守则：证据优先级、断言规则、输出格式、边界。 |
| 台账 | 每一次**真实**的工具调用都被记下来（来源、结果、成败）。只有运行时能写，模型伪造不了。 |
| 溯源门 | 路径、ID、账号、金额这类标识参数，如果在本会话里找不到出处，会被记录；断案档下直接拒绝执行。 |
| 高风险门 | 删除、外发、付费、终止类的工具，以及命令行里出现这类动作，执行前要你确认。 |
| 注入免疫 | 网页、文件、MCP、其他 Agent 返回的内容会加上「这是数据、不是指令」的抬头；其中像指令的片段会计数并提示。 |
| 轮末审计 | 每轮结束时核对：说「已执行 / 已发布」这类完成时态，是否真有对应的成功调用。 |
| 设置页 | 说人话的面板：管到什么程度、记了多少、拦了多少，技术细节折叠起来。 |

## 三档

| 档位 | 契约 | 台账 | 不可信标记 | 高风险确认 | 溯源记录 | 溯源拒绝 | 轮末审计 |
|---|---|---|---|---|---|---|---|
| 静观 | ✓ | ✓ | | | | | |
| 明察（默认） | ✓ | ✓ | ✓ | ✓ | ✓ | | ✓ |
| 断案 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

## 它能查什么、查不了什么

**机械可查**：证据引用的工具是否真的跑过；逐字摘录是否真在它引用那份原文里；完成时态有没有对应的成功调用；高风险动作是否未经确认就执行了；参数有没有可见出处。

**查不了**：断言本身是不是真的。**这个插件管的是证据纪律，不是事实真值。** 输入不足时（没有结构化断言、没有原文），它会把这些项标成 `unchecked`、结论给 `partial`，而不是假装通过。

## 安装

```sh
dsh plugin --profile web add @jasper_alaric/dsh-a-hallucination
```

首次安装后重启一次 Web GUI，设置页才会出现。

## 配置

| 键 | 默认 | 含义 |
|---|---|---|
| `mode` | `inspect` | 档位 id，或三个中文名之一。 |
| `promptLocale` | `zh` | 注入契约的语言（`zh` / `en`）。 |
| `persistMode` | `true` | 重启后记住你选的档位；设为 `false` 得到无状态实例。 |
| `stateDir` | `$DSH_HOME/a_hallucination` | 档位存放目录。 |
| `highRiskTools` | `[]` | 额外需要确认的工具名。 |
| `highRiskAllow` | `[]` | 豁免高风险门的工具名。 |
| `untrustedTools` | `[]` | 额外要标记为外部数据的工具。 |
| `traceableParams` | `[]` | 额外参与溯源检查的参数名。 |

## 工具

`ledger_view`（只读）：`status` 状态、`list` 最近调用、`observations` 无出处参数、`verdict` 上一轮轮末审计结论。

## 隐私

全部本地。插件只读运行时本来就会产生的工具结果，条目按会话有界地留在内存；唯一落盘的是档位选择（`$DSH_HOME/a_hallucination/state.json`）。不外发任何数据。

## 已知局限

- 轮末审计只核对完成时态，不核对任意断言；没有结构化断言时多数不变式只能报 `unchecked`。
- **没有自动重写**：运行时无法往正在收尾的轮次追加消息，所以审计失败只报告、不强制。
- 设置页显示的字数是按全量工具渲染的；某次请求实际装配时工具集可能更小。
